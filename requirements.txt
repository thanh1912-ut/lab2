# timm is required ONLY for MobileNetV4: neither torchvision 0.26 nor any released
# torchvision provides a MobileNetV4 implementation, so the official timm

# VGG16 / ResNet18 / DenseNet121 come from torchvision and do not need timm.

# Used by benchmark.py to pretty-print results/model_comparison.csv as a table.

# still written (the CSV itself is produced with the standard library `csv` module).
